# Disciplina de Grafos

Repositório contendo todos os trabalhos, soluções e códigos desenvolvidos na disciplina de **Grafos** do Semestre 5.

## 📚 Estrutura do Repositório

Este repositório está organizado em três avaliações principais:

### 📁 AV1 - Primeira Avaliação
Implementação dos conceitos fundamentais de grafos:
- **trab1.py** - Trabalho 1
- **trab2.py** - Trabalho 2
- **trab3.py** - Trabalho 3
- **Trab1.pdf, Trab2.pdf, Trab3.pdf** - Enunciados e especificações

### 📁 AV2 - Segunda Avaliação
Continuação com algoritmos e estruturas mais avançadas:
- **trab4.py** - Trabalho 4
- **trab5.py** - Trabalho 5
- **trab6.py** - Trabalho 6
- **Trab4.pdf, Trab5.pdf, Trab6.pdf** - Enunciados e especificações

### 📁 AV3 - Terceira Avaliação (Trabalho Final)
Projeto final integrando todos os conceitos aprendidos:
- **trabFinal.py** - Implementação do projeto final
- **README_trabFinal.md** - Documentação específica do trabalho final
- **INSTRUÇÕES_OSM.md** - Instruções especiais do projeto
- **cache/** - Arquivos de cache para otimização

## 🎯 Objetivo

Esta disciplina aborda a teoria e aplicação prática de grafos, incluindo:
- Representação de grafos
- Algoritmos de busca (BFS, DFS)
- Caminhos mais curtos
- Árvores geradoras
- Análise de conectividade
- E muito mais!
